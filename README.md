## Описание проекта
Автоматизированное тестирование веб-приложения **Stellar Burgers** (`https://stellarburgers.education-services.ru/`) в браузерах **Google Chrome** и **Mozilla Firefox** с использованием паттерна Page Object Model (POM) и формированием отчёта Allure.

### Покрытая функциональность:
1. **Основная функциональность** (`tests/test_main_functionality.py`):
   * переход по клику на раздел "Конструктор";
   * переход по клику на раздел "Лента заказов";
   * появление всплывающего окна с деталями при клике на ингредиент;
   * закрытие всплывающего окна кликом по крестику;
   * увеличение счётчика ингредиента при добавлении его в заказ.
2. **Раздел "Лента заказов"** (`tests/test_order_feed.py`):
   * увеличение счётчика "Выполнено за всё время" при создании нового заказа;
   * увеличение счётчика "Выполнено за сегодня" при создании нового заказа;
   * появление номера оформленного заказа в разделе "В работе".

## Архитектура проекта
* `locators/` - пакет с локаторами элементов, распределёнными по страницам (`main_page_locators.py`, `login_page_locators.py`, `order_feed_locators.py`).
* `pages/` - пакет Page Objects (`base_page.py`, `main_page.py`, `login_page.py`, `order_feed_page.py`).
* `tests/` - тестовые сценарии, сгруппированные по функциональности (`test_main_functionality.py`, `test_order_feed.py`).
* `data.py` - URL-адреса сервиса и тестовые константы.
* `helpers.py` - генерация тестовых данных и методы API для создания и удаления пользователя.
* `conftest.py` - кроссбраузерная фикстура `driver` (Chrome и Firefox), фикстура создания/удаления пользователя через API (`yield` teardown) и фикстура авторизации.
* `allure_results/` - артефакты для генерации отчёта Allure.
* `requirements.txt` - список зависимостей проекта.
* `.gitignore` - исключение кэша и виртуального окружения.
